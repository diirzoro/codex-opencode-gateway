**الحالة: ملغاة بالكامل كمصدر تعليمات تنفيذية.**

بناء على قرار المالك، أُزيلت من هذا الملف جميع الأوامر وخطط التشغيل والسياسات المتعاقبة التي كانت تتداخل وتتناقض. يحتفظ تاريخ Git بالأدلة الأصلية عند الحاجة إلى تحقيق تقني فقط، **ولا يجوز استخدام أي سطر منها لتوجيه تنفيذ جديد**.

## المسار المعتمد غير القابل للرجوع إلى النظام القديم
```text
Client → Nginx → Python (identity/ownership/policy verification)
                       └─ X-Accel-Redirect → internal Nginx → OpenCode Native
OpenCode Native → Nginx → Client (model response, JSON, SSE)
```
تدخل Python في **فحص كل طلب** مسموح بل مطلوب بحسب الملكية والسياسة. **رد النموذج لا يرجع إلى Python**. Native وحده يدير المحادثات والرسائل والنماذج والمزودين والوكلاء والأدوات والأذونات وSSE والتخزين؛ لا محرك موازٍ ولا Native منفصل لكل Workspace.

## الحالة الواقعية التي لم تحل بمجرد التوثيق
- سجل VPS في 29 أكتوبر يُظهر HTTP409 متكررة لـWorkspace sessions، وHTTP200 واحدًا لـprompt_async دون إثبات اكتمال الرد.
- تحديث source `e1fa147bfe77` لم يكن منشورًا على TEST عند توثيقه؛ يلزم تحقق deployed SHA.
- إصلاح مصدر رفع المرفقات `a183083ddc97` يزيل مسح حصة مكررًا، **لا** يمثل اختبار رفع ناجحًا على TEST.
- GitHub registry جدول `github_identity_registry` موجود حسب فحص المالك، لكن وجوده لا يثبت وجود كل الأعمدة أو Alembic current heads أو عمل OAuth/OTP.
- GitHub callback ما زال قد يرجع `configuration` أو `ownership-review`. يجب تحديد سبب الرفض الآمن من سجلات TEST وفحص الأعمدة/الملكية، دون تجاوز حماية مستخدم آخر.
- ممنوع حذف ملفات/جلسات أو تشغيل LIVE/master أو تغيير Native/Nginx/DB/env/ports أو نشر تلقائي لعلاج مشاكل غير مثبتة.

**هذا الملف إشعار إلغاء فقط، وليس مذكرة موازية.** لا تُعاد إضافة قرارات تشغيل إليه. حدّث المذكرة المتخصصة ذات الصلة عند توفر دليل جديد.
