المرجع: رسالة المنتج المرفقة والصورة التي أرسلها المستخدم. لم يُفتح رابط VPS ولم تُستخدم SSH أو حسابات الإنتاج. هذه مراجعة الكود المحلي؛ ليست شهادة بحالة الخادم. لا رفع أو نشر قبل مراجعة هذا التقرير.

## الهدف المعتمد

بوابة اشتراك تحمل علامتنا وتتيح للعميل استخدام OpenCode في مساحة عمل تخصه، مع GitHub ومزوّد AI يخصانه. Gateway يدير الهوية والاشتراك والملكية ودورة حياة العمل، وOpenCode ينفذ البرمجة. الإدارة تدير المنصة والعملاء ولا تدخل محرر أكوادهم.

قائمة العميل المستهدفة: **مساحة العمل / الرئيسية، المشاريع، الجلسات، الاشتراك والفوترة، الحساب، الأمان، الإعدادات والاتصالات**. Dashboard منفصل زائد عن هذه القائمة. GitHub والمزوّدات اتصالات للمحادثة وليسا تطبيقين منفصلين.

قرار المستخدم الصريح: **الاشتراكات غير قابلة لاسترداد المبلغ**. يُعرض هذا في الأسعار والدفع. لا يُفهم إلغاء الاشتراك أو الحساب على أنه استرداد، ولا تُختلق معاملات استرداد.

## 1. ما يُبقى

- توجيه العميل إلى Workspace/Home والإدارة/المالك إلى Overview.
- المشاريع والجلسات المملوكة للعميل، إنشاء Blank/Template أو استيراد GitHub، الملفات وDiff وCommit.
- أدوات agent/provider/model/GitHub قرب المحرر، وSettings/Connections للربط.
- النماذج المنبثقة المتمركزة، الألوان الهادئة، RTL/LTR، والعودة إلى Landing من الشعار.
- تجربة عشرة أيام، تحقق الاستحقاق من الخادم، وطلبات تحويل يدوية مرتبطة بالعميل لا تتفعّل بمجرد إدخال مرجع.
- واجهة إدارة واحدة؛ البيانات المتاحة فعليًا فقط، دون محرر مشاريع العملاء.

## 2. ما يُبسّط

- إزالة Dashboard من تنقل العميل؛ البداية مساحة عمل ومشاريع ومحادثات، لا بطاقات إدارة.
- الفوترة: الخطة، حالة الوصول، الأيام المتبقية وتاريخ الانتهاء، اختيار خطة/تجديد، وطلبات الدفع الحقيقية. إزالة بطاقات «الخطة المحددة» المتكررة وعناصر فواتير/مدفوعات غير منفذة.
- إعادة ربط زر التجديد باختيار خطة ومسار checkout الحالي بدل API renew الذي يرجع 503.
- إبقاء الأمن والحساب صغيرين، وتجنب حقول إدارية داخل نموذج العميل.
- توحيد محتوى Provider/GitHub بدل مضاعفته بين صفحات وألواح. لا يُضاف لوح دائم جديد لمجرد وجود API.

## 3. ما يُنقل

- تهيئة مفاتيح المزوّدات وتفويض GitHub إلى Settings/Connections؛ الاختيار أثناء العمل يبقى قرب المحرر.
- الدفع وسياسة عدم الاسترداد إلى الأسعار/checkout/Fوترة العميل.
- إعداد وسائل استلام المنصة والسياسات والصلاحيات إلى الإدارة فقط.
- الملفات والتغييرات والنشاط ولوح الجلسات إلى سياق مساحة العمل؛ لا تظهر الألواح في الحساب أو الفوترة.

## 4. ما يُزال من الواجهة

- Dashboard الزائد في قائمة العميل.
- عناوين وفواتير فارغة لا تستند إلى سجل حقيقي، وزر تجديد غير موصول بعملية متاحة.
- التلميحات القديمة بأن لوحة العميل وجهة الحساب الأساسية.
- لا يُزال الكود الخلفي أو سجل الدفع، ولا تُحذف تغييرات المشروع السابقة.

## 5. ما يُربط بوظائف OpenCode القائمة

الكود المحلي يستخدم `/session` و`/session/{id}/message` و`/agent` و`/provider` وعمليات credentials/OAuth وabort/permissions من OpenCode، عبر Gateway. المطلوب تطوير المحادثة على هذه الوظائف، وليس بناء محرك موازٍ.

الحدود الحالية: رسائل المحادثة تُحوّل إلى role/text؛ أحداث التنفيذ الأساسية محفوظة محليًا وليست جسرًا كاملًا لكل أحداث وأجزاء OpenCode. لذلك إخراج الأدوات والتدفق والمعاينة لم يصل إلى تجربة OpenCode الكاملة. لا يُستخدم iframe أو توجيه المتصفح إلى منفذ OpenCode العام.

## ترتيب العمل التالي

1. تطبيق تبسيط التنقل والفوترة وإظهار عدم الاسترداد دون زيادة صفحات.
2. إثبات المحادثة الحية والأحداث والأذونات عبر OpenCode ببيانات اعتماد العميل، داخل بيئة اختبار مصرّح بها.
3. تبديل الفرع مع الحفاظ على التغييرات، وإثبات GitHub clone/push/revoke.
4. عزل نظامي وشبكي وحدود موارد ومشرف runtimes قبل خدمة عملاء غير موثوقين.
5. Preview آمن؛ وبوابة دفع إلكتروني إذا أُريد تحصيل تلقائي.

لا يُعلن أن المنصة صالحة للنشر العام لمجرد تشابه الواجهة أو نجاح اختبارات محلية. لا تُنقل الأسرار ولا يُفتح الخادم في هذه المرحلة.

## تبسيط محلي طُبّق بعد المراجعة

- أُزيل Dashboard الزائد من قائمة العميل، فأصبحت سبعة أقسام كما في الرسالة.
- صفحة Workspace/Home ترتب المشاريع وبحث المحادثات في مساحة المحتوى دون إضافة sidebar ثابت جديد؛ يتدرج العرض إلى عمود واحد على الشاشات الضيقة.
- ملخص الفوترة يعرض الخطة، المتبقي، حالة الوصول، والانتهاء. حُسب المتبقي من الاشتراك الفعّال أو التجربة، وليس من التجربة دائمًا.
- أُزيلت واجهات الفواتير/المدفوعات غير المنفذة؛ بقي سجل طلبات التحويل الحقيقي. التجديد يفتح checkout للخطة بدلاً من استدعاء renew غير المنفذ.
- سياسة «الاشتراكات غير قابلة لاسترداد المبلغ» ظاهرة في الأسعار والفوترة وcheckout بالعربية والإنجليزية.
- التغييرات في `dashboards.js` و`enhancements.js` و`index.html` فقط، دون API أو migration جديدة. ثمانية اختبارات Chromium مرئية نجحت بعد التبسيط، وتُفحّصت صورة صفحة البداية المحلية.
- لا نشر ولا push ولا اتصال VPS. لا تُعتبر هذه التعديلات ربطًا حيًا أو استكمالًا للعزل أو Preview أو الدفع الإلكتروني.
