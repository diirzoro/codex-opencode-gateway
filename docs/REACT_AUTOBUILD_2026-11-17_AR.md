# بناء React التلقائي — تحديث 17 نوفمبر 2026

## السلوك المطلوب

إعداد واحد على السيرفر لكل الحسابات، دون إعداد Docker أو منفذ أو خدمة من العميل. عند الضغط على المعاينة في مشروع React/Vite يدعم npm، تُجهز الاعتماديات العامة الموثقة في package-lock.json ثم يُنفذ البناء داخل العامل القائم. تتوقف الحاوية قبل نشر ملفات dist، وتبقى المعاينة خدمة ملفات محدودة بملكية المشروع والجلسة والرابط المؤقت. لا يُنفذ بناء أو تنزيل حزم مع رسائل المحادثة.

## التنفيذ والحدود

- تنزيل أرشيفات npm العامة فقط عبر HTTPS من registry.npmjs.org دون تحويلات أو بيانات اعتماد. تحقق SHA-512 في Gateway ثم مرة أخرى داخل العامل قبل تمرير الأرشيفات للحاوية.
- لا يُرسل المصدر إلى npm أو GitHub Actions. تُشارك أرشيفات الحزم العامة الثابتة فقط في مخزن محدود، ولا تُشارك نتائج المشاريع بين العملاء.
- npm ci يعمل دون شبكة ومع تعطيل install/preinstall/postinstall. أمر build المقصود وتهيئة Vite يعملان داخل الحاوية فقط، دون مفاتيح أو قاعدة بيانات أو socket للتحكم.
- نفس صورة Node الموثقة الموجودة؛ لا صورة تطبيق لكل عميل ولا خدمة دائمة جديدة. تبقى الشبكة none والمصدر للقراءة فقط والهوية 10001 وسقف المعالج 0.5 والذاكرة 768 MiB والعمليات 128.
- للبناء مساحة /build مؤقتة 384 MiB تسمح بتنفيذ أدوات البناء الأصلية داخل الحاوية؛ /tmp يبقى 64 MiB مع noexec. لا يُفتح أي مسار قابل للكتابة على المضيف.
- مهلة البناء 120 ثانية. المصدر والحزم معًا حتى 50 MiB، والحزم المضغوطة حتى 20 MiB وبحد 8 MiB للحزمة و250 حزمة. الناتج حتى 20 MiB، والملف المعروض حتى 2 MiB. المخزن العام يُنظّف حسب العمر والحجم وعدد الملفات.
- لا تصدر منحة تصفح أثناء البناء. الإلغاء يمنع نشر نتيجة متأخرة. الملفات غير المتغيرة تعيد استخدام الناتج دون بناء جديد؛ التحديث الصريح يعيد البناء.
- لا تُنسخ .env أو .npmrc أو .yarnrc أو .netrc أو مفاتيح الشهادات إلى بيئة البناء. تُرفض الروابط وتجاوز المسارات والملفات غير العادية عند تصدير المصدر وقراءة ناتج البناء.

## نطاق الدعم

React/Vite مع package-lock.json إصدار 2 أو 3 وأمر build ينتج dist/index.html. الحزم الخاصة، وعناوين Git، والاعتماديات المحلية/روابط workspaces، وpnpm/yarn ليست مفعلة تلقائيًا في هذه الدفعة. لا تُغيّر ملفات مشروع العميل أو lockfile لمعالجة عدم التوافق، ولا يُعرض index.html غير المبني كنجاح بديل عند فشل البناء.

## التحقق والنشر

اجتازت المجموعة المحلية 93 اختبارًا، منها npm فعلي دون شبكة من حزمة اختبار ذات SHA-512، والتأكد من عدم تشغيل preinstall، وإلغاء البناء أثناء تصدير الناتج، ومنع منحة القراءة أثناء البناء، وإعادة استخدام الناتج غير المتغير. فحوص صياغة الواجهة والمشغل نجحت. لا تعوض هذه النتائج الاختبار الحي.

العملية react_build_activate تختبر React/Vite فعليًا بملفات اختبار مولّدة وحزم عامة، وتتحقق من توقف حاوية البناء قبل العرض. تحفظ نسخة من الملفات والإعداد العام وتعيدها عند الفشل. الأثر: إعادة تشغيل Gateway وعامل المعاينة فقط، مع رفض النشر إذا كانت معاينة ديناميكية قيد التشغيل. لا تعديل لقاعدة البيانات أو Pi أو Nginx، ولا ترحيل بيانات.

حالة النشر والاختبار الحي: قيد التنفيذ، ولم تُسجل PASS بعد.
