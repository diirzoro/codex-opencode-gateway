## تعريف المنتج وحقوق المستخدم
الرسوم تغطي **الوصول إلى منصة OpenCode Gateway، واجهة ومساحات العمل، استيراد/تعديل المشاريع المحلية ومشاريع GitHub، التخزين المؤقت، والخدمات المجانية المضمنة والمتاحة فعليًا**. **لا تشمل أي API مدفوع أو اشتراكات/رصيد نماذج ذكاء اصطناعي**. يُدخل العميل بنفسه API keys أو OAuth الخاص بمزودي AI الذين يختارهم (BYOK/BYOA)، ورسومهم عليهم مباشرة إن فرضوها. لا تدّعي البطاقات أن هناك نماذج مجانية مضمونة دائمًا. هذا النص واضح في بطاقات الباقات، وصفحة الدفع، والتفاصيل.

- **اشتراك واحد وحصة واحدة لكل عميل**: المستخدم + المتبقي مجموعهما ثابت سواء عمل العميل على GitHub أو مشروع محلي؛ لا تسعير خاص بـGitHub. التخزين البعيد في GitHub.com لا يُحسب. واجهات GitHub والمحلي تعرض إجماليًا متطابقًا مع تفصيل مساحتين فقط.
- الأسعار **مقابل استخدام المنصة لا API**. العميل هو المسؤول عن مفاتيح ونماذج مزوّديه؛ لا تخصم رسوم AI من الباقة. كل خدمات المنصة المجانية المتاحة تبقى وفق حدودها التشغيلية.
- الخطط القديمة وأسعار فترات الاشتراك الحالية محفوظة كسجلات تاريخية والاشتراكات المدفوعة السابقة لا تُقصّر مدتها. إطلاق الرموز الجديدة للخطط بأسماء وحصص صريحة، وعدم استبدال السجلات/الفواتير القديمة أو إعادة تفعيل التجربة بعد أول دفع.
- يجب حساب جميع الملفات الفعلية للمشروع على Gateway بما فيها metadata ضمن نسخة العمل المحلية، بما لا يؤدي إلى حساب سعة مستودع GitHub البعيد.
- عند 80% تنبيه، 95% تحذير، 100% منع عمليات الإنشاء والرفع والكتابة الجديدة التي تزيد الاستهلاك، مع توفير التصدير/المزامنة الآمنة. لا حذف تلقائي أو مسح مستودع بعيد عند تجاوز حد الخطة، ولا مساس بملفات العملاء الحاليين.
- سياسات احتفاظ الكاش مستقلة: GitHub 73 ساعة والمشاريع المحلية 7 أيام مع المحافظة على التعديلات غير المحفوظة وفحص Native قبل أي تنظيف.

## واجهات المستخدم والاختبارات المطلوبة

1. في رأس لوحة العميل وبطاقتي **المشاريع المحلية** و**مشاريع GitHub**: «الإجمالي المستخدم، إجمالي الحصة، المتبقي، نسبة الاستهلاك» من API الخادم ذاته. تظهر مساهمة المحلي وGitHub كل على حدة، مع بقاء إجمالي الحصة موحدًا (ولا يعرض كل قسم 50/512 كأنهما باقتان).
2. بطاقات التجربة/الاشتراك الثلاث: الاسم، السعر والمدة والحجم، تغطية GitHub + المحلي، تنبيه صريح: «اشتراك استخدام المنصة؛ مفاتيح AI/API الخاصة بك، غير مشمولة». الرسالة بالعربية والإنجليزية مع RTL صحيح.
3. الوصول التخزيني يقرره الخادم عند استيراد المستودع ورفع الملفات وإنشاء جلسة Native والتفاعل معه، وليس المتصفح. يطبّق على جميع Workspaces للحساب ولا يعزل GitHub بحصة موازية.
4. عندما يتجاوز العميل الحد بسبب downgrade أو النسخ القديمة، لا تحذف شيئًا؛ اشرح المنع مع خيارات تقليل الاستخدام والتصدير والترقية.
5. اختبار حسابين، مستودعين GitHub، مشروعين داخليين، وعمليات متوازية مع تحقق من سلامة ملكية الملفات والفواتير والدفع. لا تفترض نجاح نشر TEST قبل ظهور نتيجة GitHub Actions واختبار فعلي.
